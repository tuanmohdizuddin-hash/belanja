# Belanja ✦ Penjejak Perbelanjaan Harian

Aplikasi web (PWA) untuk menjejak perbelanjaan harian menggunakan **suara** atau **taip**, dengan dashboard premium bertema **silver & gold**.

## Ciri-ciri
- 🎙 **Input suara** (Bahasa Melayu, `ms-MY`) — sebut sahaja: *"nasi lemak lima ringgit lima puluh sen"*
- ⌨ **Input taip bahasa biasa** — `teh tarik 2.50 dan roti canai 1.50` (banyak item sekaligus)
- ✨ **Kategori automatik** (Makanan, **Perodua 524**, Pengangkutan, Bil, Barang Dapur, Shopping, Hiburan, Kesihatan) — boleh pilih manual
- 📅 Faham `semalam` / `kelmarin`
- 📊 Dashboard: jumlah bulan ini, bajet & baki harian, trend 7/14/30 hari, carta kategori, insight & unjuran akhir bulan
- ✏️ Edit / padam transaksi, butang **Batal** (undo), carian
- 📄 **Laporan profesional** (`report.html`) — siap nama, no. rujukan, ringkasan eksekutif, carta, pecahan kategori, 5 belanja terbesar, senarai transaksi & ruang tandatangan. Pilih bulan / 7 hari / 30 hari / 3 bulan / tahunan, kemudian **Cetak / Simpan PDF** (A4)
- ⬇️ Eksport CSV (boleh buka di Excel / Google Sheets)
- 📱 Boleh dipasang di telefon (PWA) & berfungsi offline
- 🔒 Data disimpan dalam peranti sahaja (localStorage)

## Cara guna
Buka `index.html` dalam pelayar, atau hos secara percuma di **GitHub Pages**
(Settings → Pages → Deploy from branch). Input suara memerlukan **HTTPS** dan
pelayar yang menyokong Web Speech API (Chrome Android/desktop, Safari iOS 14.5+).
